# DOMAIN HUNTER PRO

DOMAIN HUNTER PRO — это локальная CRM-панель для ручного поиска, очистки, классификации, RDAP-проверки, хранения, мониторинга и экспорта доменов.

Система открывается в браузере и работает с локальной базой SQLite. Автоматических проверок по расписанию нет: сбор, повторная проверка и экспорт запускаются только пользователем.

## Требования

- Python 3.12+
- Доступ в интернет для установки зависимостей, сбора доменов и RDAP-проверок
- Браузер для работы с Dashboard

## Установка и запуск

Выполните команды из корня репозитория:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn domain_hunter.backend.app:app --host 127.0.0.1 --port 5000
```

После запуска откройте в браузере:

- http://127.0.0.1:5000
- или http://localhost:5000

Если порт `5000` занят, можно указать другой порт, например:

```bash
uvicorn domain_hunter.backend.app:app --host 127.0.0.1 --port 8000
```

и открыть http://127.0.0.1:8000.


## Источники доменов и важное ограничение

Система больше не генерирует домены «наугад». В базу попадают только домены, найденные или взятые из реальных источников:

- `custom` — пользовательский файл `domain_hunter/config/custom_domains.txt`;
- `github` — поиск репозиториев GitHub и их homepage-ссылок;
- `producthunt` — страницы поиска Product Hunt;
- `company_directories` — каталоги/доски G2, Capterra, TrustRadius;
- `startup_directories` — YC Companies, BetaList, Crunchbase;
- `search_engines` — поисковая выдача DuckDuckGo по официальным сайтам компаний;
- `curated_company_catalog` — fallback-список известных реальных компаний и продуктов, чтобы система не была пустой при блокировке сетевых каталогов.

Если каталог блокирует запросы, сеть недоступна или источник не отдает внешние ссылки, результатов будет меньше указанного лимита. Это лучше, чем добавлять фейковые сгенерированные домены. В таблице доменов есть колонка «Источник», по которой видно, откуда пришла запись.

## Что смотреть в интерфейсе

### 1. Главная панель — Dashboard

Адрес: http://127.0.0.1:5000/

На главном экране отображаются:

- текущая дата;
- общая статистика по базе;
- количество доменов по ключевым категориям: Crypto, Finance, Hosting, AI, Shopping, Education, VPN, Other;
- домены, которые освобождаются сегодня;
- домены, которые освобождаются завтра;
- домены, которые освобождаются в течение 7 дней;
- домены, которые освобождаются в течение 30 дней;
- ТОП перспективных доменов;
- избранные домены;
- последние добавленные домены;
- домены с пользовательскими заметками.

С этой страницы также можно быстро запустить сбор доменов: укажите тематику, например `crypto finance`, количество и нажмите `Collect`.

### 2. Список доменов

Адрес: http://127.0.0.1:5000/domains

На этой странице можно:

- смотреть таблицу доменов;
- искать по домену, ключевому слову, заметкам или регистратору;
- фильтровать по категории;
- фильтровать по статусу;
- фильтровать по месяцу окончания регистрации;
- фильтровать по минимальному рейтингу;
- вручную добавить домен;
- вручную запустить повторную проверку группы доменов.

Примеры фильтрации:

- категория `crypto` + статус `pendingDelete`;
- категория `finance` + месяц `June`;
- рейтинг от `80` и выше.

### 3. Карточка домена

Откройте любой домен из таблицы кликом по имени.

В карточке отображаются:

- домен;
- категория;
- источник;
- регистратор;
- дата создания;
- дата окончания;
- дата обновления;
- статус;
- возраст домена;
- рейтинг;
- история RDAP-проверок.

В блоке «Мой ежедневник» можно поставить метку:

- ⭐ Интересный;
- 🔥 Очень интересный;
- ❌ Не интересен;

и сохранить собственные заметки, например: «проверить владельца», «хороший бренд», «возможно заброшенный бизнес».

### 4. Календарь доменов

Адрес: http://127.0.0.1:5000/calendar

Календарь показывает домены, сгруппированные по дням окончания регистрации в выбранном месяце. Если у домена заполнена дата окончания, он появится в соответствующем дне.

### 5. Экспорт

Экспорт доступен через ссылки в верхнем меню:

- `CSV` — http://127.0.0.1:5000/export/csv
- `XLSX` — http://127.0.0.1:5000/export/xlsx
- `TXT` — http://127.0.0.1:5000/export/txt

Экспорт сохраняет данные из SQLite в файл выбранного формата и отдает его браузеру для скачивания.

## Как пользоваться через CLI

Команды выполняются из корня репозитория при активированном виртуальном окружении.

### Сбор доменов

```bash
python -m domain_hunter.backend.cli collect crypto 1000
python -m domain_hunter.backend.cli collect finance 500
python -m domain_hunter.backend.cli collect hosting 300
```

Формат команды:

```bash
python -m domain_hunter.backend.cli collect <тема> <количество>
```

### Повторная проверка RDAP

```bash
python -m domain_hunter.backend.cli check all
python -m domain_hunter.backend.cli check crypto
python -m domain_hunter.backend.cli check finance
```

Проверка запускается вручную. Система не выполняет фоновые проверки по расписанию.

### Экспорт

```bash
python -m domain_hunter.backend.cli export csv
python -m domain_hunter.backend.cli export xlsx
python -m domain_hunter.backend.cli export txt
```

## Где хранятся данные

- SQLite база: `domain_hunter/database/domains.sqlite3`
- Экспортированные файлы: `domain_hunter/results/exports/`
- Сортировка результатов по месяцам и статусам: `domain_hunter/results/`
- Пользовательские источники: `domain_hunter/config/custom_domains.txt`
- Модули источников: `domain_hunter/sources/`

## Как добавить свои домены

### Через интерфейс

1. Откройте http://127.0.0.1:5000/domains.
2. В блоке `Add domain` укажите домен, категорию и при необходимости дату окончания.
3. Нажмите `Add`.

### Через файл пользовательского источника

Создайте файл:

```text
domain_hunter/config/custom_domains.txt
```

Добавьте домены построчно:

```text
example.com
coin-example.com
hosting-example.net
```

После этого запустите сбор через Dashboard или CLI. Источник `custom` подхватит домены из файла.

## Как добавить новый источник

Добавьте новый файл в папку `domain_hunter/sources/`, например `my_source.py`, и создайте класс `Source`:

```python
class Source:
    name = "my_source"

    def collect(self, keywords: list[str], limit: int) -> list[str]:
        return ["example.com"]
```

Collector автоматически найдет модуль при следующем запуске сбора. Менять ядро системы не нужно.

## Быстрая проверка после запуска

1. Откройте http://127.0.0.1:5000.
2. В поле сбора укажите `crypto finance` и количество `50`.
3. Нажмите `Collect`.
4. Перейдите на http://127.0.0.1:5000/domains и проверьте, появились ли домены.
5. Откройте карточку любого домена и добавьте заметку.
6. Скачайте CSV через http://127.0.0.1:5000/export/csv.
