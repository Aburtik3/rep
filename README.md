# Domain Expiration Monitor

Локальная веб-страница для массовой проверки сроков продления доменов. Подходит для списка из сотен и тысяч доменов: вставляете домены, нажимаете проверку и получаете HTML-таблицу с цветовой приоритизацией.

## Возможности

- Проверка через бесплатные источники без платных ключей:
  - RDAP registry lookup по bootstrap-файлу IANA;
  - классический WHOIS с прямыми серверами популярных зон и fallback через `whois.iana.org`;
  - дополнительная перепроверка потенциально свободных доменов через DNS и внешний `whois-service.ru`.
- Поддержка IDN-доменов (`пример.рф`) через punycode/IDNA.
- Поддомены автоматически сворачиваются до основного регистрируемого домена: `asia.payments.com` проверяется как `payments.com`, `global.alipay.com` — как `alipay.com`.
- Домен помечается свободным/критичным только если свободу подтвердили минимум два источника; если `whois-service.ru` или DNS подтверждают занятость, строка не будет отмечена как свободная.
- Цвета в таблице:
  - зелёный — до окончания больше 6 месяцев;
  - жёлтый — от 1 до 6 месяцев;
  - ярко-красный — от 1 недели до 1 месяца;
  - тёмно-красный — домен свободен, просрочен или осталось до 7 дней.
- Отдельные столбцы с датой окончания и точным часом окончания в UTC, чтобы было проще ловить критичные домены.
- Отображение источников, расхождений между источниками и уровня уверенности.
- Компактная таблица: один домен — одна строка, самые срочные/свободные домены сортируются сверху.
- Результаты появляются по мере проверки, не нужно ждать завершения всех 1000 доменов.
- Ручное обновление любой строки кнопкой **Обновить** и массовое обновление строк **Не удалось проверить** кнопкой **Обновить неудачные**.
- Опциональное автообновление неудачных строк каждые 5 минут.
- Экспорт результатов в CSV, включая дату и час окончания.
- Только стандартная библиотека Python: не нужно ставить зависимости.

## Запуск

Требуется Python 3.10+.

```bash
python3 domain_monitor.py --host 127.0.0.1 --port 8080
```

Откройте в браузере:

```text
http://127.0.0.1:8080/
```

Если программу нужно открыть с другого компьютера в локальной сети, запустите так:

```bash
python3 domain_monitor.py --host 0.0.0.0 --port 8080
```

## Как пользоваться

1. Вставьте список доменов — по одному на строку или через пробел/запятую.
2. Нажмите **Проверить домены** — строки будут появляться сразу по мере готовности, а не только после окончания всей пачки.
3. Сначала обрабатывайте верх таблицы: тёмно-красные и ярко-красные строки автоматически сортируются выше остальных.
4. Смотрите отдельные колонки **Дата окончания** и **Час окончания UTC** для доменов, которые нужно срочно продлить или перехватить после освобождения.
5. Если строка попала в **Не удалось проверить**, нажмите **Обновить** в этой строке или **Обновить неудачные** над таблицей — обновление обходит часовой кэш и заново идёт в RDAP/WHOIS.
6. Если нужно оставить страницу открытой, включите галочку **автообновлять неудачные каждые 5 минут**.
7. В колонке **Источники и заметки** раскрывайте детали, если дата выглядит подозрительно или источники расходятся.
8. При необходимости скачайте CSV.

## Важные замечания

WHOIS/RDAP и внешние веб-сервисы — публичные сетевые источники. У некоторых зон бывают лимиты, временные сбои, таймауты чтения (`The read operation timed out`), блокировки внешнего HTTP-сервиса или скрытие точной даты окончания. Поэтому программа показывает источники, не останавливает всю проверку из-за одного таймаута и предупреждает о расхождениях, но для критичных доменов всё равно стоит сверять дату в кабинете регистратора.

Для `.ru`, `.рф` и `.su` используется WHOIS `whois.tcinet.ru`, где часто встречаются поля вроде:

```text
Зарегистрирован: 2007-10-26T20:00:00Z
Оплачен до:      2026-10-26T21:00:00Z
```

Именно поле `Оплачен до` используется как дата окончания оплаты.
